## Specs
- S1 — "generes un detallado de cada flujo que deba ser implementado y que sea importante para el usuario final": a document listing each end-user flow with status (complete / partial / missing) and, for partial or missing ones, goal, steps, edge cases, endpoints, acceptance criteria and priority. Documentation only; implementing those flows is not authorized by this request.
- S2 — "mejora seguridad": apply the hardening fixes backed by audit evidence in `api/`, `web/`, `deploy/` and CI. Assumption (parent): changes that need an external account step, a new dependency or a data migration are listed for the user instead of applied.
- S3 — "seo": metadata, crawler files, structured data and static fallback content for the single indexable URL `https://app.magnifit.co/`.
- S4 — "y otros parametros utiles de la aplicación": PWA manifest completeness, accessibility and cache/header configuration found by the audit. Assumption (parent): no product behavior change.
- S5 — "orquestes a opus y sonnet": audits delegated to Opus (flows, security) and Sonnet (SEO/PWA/performance); the parent implements.
